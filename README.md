# my-steam

my-steam é uma recriação da Steam para a web, construída aos poucos como
projeto de aprendizado — tanto de desenvolvimento web quanto de
desenvolvimento assistido por IA.

A Steam é a especificação: quando surge a dúvida de como algo deveria
funcionar, a resposta é como a Steam faz. Não há jogos, pagamentos ou usuários
reais — os "jogos" são pequenos programas em C compilados para WebAssembly,
que exibem o próprio nome ao rodar.

A documentação começa em [docs/README.md](docs/README.md): o produto em
[docs/product/](docs/product/), as convenções de trabalho em
[docs/devsecops/](docs/devsecops/) e as decisões de arquitetura em
[docs/adr/](docs/adr/).

[CLAUDE.md](CLAUDE.md).
