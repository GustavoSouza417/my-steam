# Visão geral do produto

## O que é

Uma cópia da Steam, para web.

Não é "inspirado na Steam", não é "uma plataforma de jogos com ideias próprias".
O objetivo é reproduzir a Steam: as mesmas áreas, os mesmos fluxos, a mesma
lógica de navegação. A Steam é a especificação.

## Por que isso importa

Copiar um produto existente e bem conhecido elimina a fase de descoberta de
requisitos. Quando surgir a dúvida "como isso deveria funcionar?", a resposta
padrão é: **abra a Steam e veja como ela faz**.

Isso libera a energia do projeto para o que realmente interessa aqui:
construir o software e aprender desenvolvimento assistido por IA.

## Natureza do projeto

Projeto pessoal de aprendizado. Sem prazo, sem usuários reais, sem operação.
Nada de jogos reais, pagamentos reais ou distribuição real de software —
tudo é simulado.

## Não-objetivos

- Inovar sobre a Steam ou "melhorar" a experiência dela.
- Ter paridade visual pixel a pixel.
- Escalabilidade, performance ou segurança de produção.
- Monetização.

## Como o escopo é tratado

O escopo total é grande e já conhecido — está em [`002-scope.md`](002-scope.md).
A construção é incremental: uma fatia funcional de cada vez, escolhida
explicitamente. O escopo completo existe como mapa, não como backlog a ser
atacado de uma vez.
